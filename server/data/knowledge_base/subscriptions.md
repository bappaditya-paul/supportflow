# Subscription Policy

## 1. Plan Tiers
* **Free Plan:** $0/month. 1 user seat, community support, 100 requests/day.
* **Pro Plan:** $9.99/month. 5 user seats, priority email support, unlimited workflows, SLA response within 4 hours.
* **Enterprise Plan:** Custom pricing. Dedicated account manager, 99.9% uptime SLA.

## 2. Plan Changes & Billing Cycles
* Upgrades take effect immediately upon transaction settlement.
* Downgrades take effect at the end of the current paid billing cycle.
* Prorated billing applies when upgrading mid-month.
